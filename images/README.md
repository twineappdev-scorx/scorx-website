# ScorX Website Images

This folder contains all image assets for the ScorX website.

## Required Images

### 1. **favicon.png**
- **Purpose**: Website favicon (browser tab icon)
- **Recommended Size**: 32x32px or 64x64px
- **Format**: PNG with transparent background
- **Used in**: All HTML pages
- **Notes**: Should feature the ScorX logo or brand mark

### 2. **app-store-badge.svg**
- **Purpose**: Apple App Store download button
- **Recommended Source**: [Apple's official App Store badges](https://developer.apple.com/app-store/marketing/guidelines/#section-badges)
- **Format**: SVG (vector)
- **Used in**:
  - index.html (hero section, footer, final CTA)
  - download.html
  - features.html
- **Notes**: Use official Apple badge to comply with App Store guidelines

### 3. **social-preview.png**
- **Purpose**: Open Graph image for social media sharing (Facebook, LinkedIn, etc.)
- **Recommended Size**: 1200x630px
- **Format**: PNG or JPG
- **Used in**: index.html (og:image meta tag)
- **Notes**: Should showcase the app interface or key features with branding

### 4. **twitter-card.jpg**
- **Purpose**: Twitter card image for tweet previews
- **Recommended Size**: 1200x675px (16:9 ratio)
- **Format**: JPG or PNG
- **Used in**: index.html (twitter:image meta tag)
- **Notes**: Can be similar to social-preview.png but optimized for Twitter's card format

## Image Optimization Tips

- Compress all images before adding them to reduce page load time
- Use WebP format where possible for better compression (with fallbacks)
- Keep file sizes under 200KB for optimal performance
- Use descriptive alt text in HTML for accessibility

## Tools for Image Optimization

- [TinyPNG](https://tinypng.com/) - PNG/JPG compression
- [SVGOMG](https://jakearchibald.github.io/svgomg/) - SVG optimization
- [Squoosh](https://squoosh.app/) - Modern image compression
